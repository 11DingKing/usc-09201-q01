# 林地权属版本账领域约定

项目面向集体林权改革与林下产业协作场景，业务记录需要区分来源、发生时间与当前有效版本。涉及个人、机构或敏感地点的信息只应向职责范围内的角色开放，所有对外结果都应能够追溯到采用的数据版本。

## 核心概念

- **宗地（parcel）**：一宗林地的主体，含宗地编号、坐落、面积与四至边界。
- **成员（member）**：承包共有人，含姓名、证件号、电话、份额。成员 ID 由宗地与其证件号派生，保证按业务时间重放时确定。
- **权利（right）**：权利类型（承包经营权、林地经营权、林木所有权等）、权利人、涉及面积与流转期限。
- **证照（certificate）**：依据某一版本签发的权属凭证。状态：`valid`（有效）→ `superseded`（被新证取代）或 `revoked`（撤回）。撤回与取代只追加新版本，历史版本中的证照状态保持不变。
- **变更依据（evidence）**：每笔变更必须携带的材料（documents / confirmed_by / note）。边界调整必须经全体共有人确认，否则阻断（`CONFIRMATION_INCOMPLETE`）。
- **版本（version）**：一次提交的不可变快照。`occurred_at` 为业务发生时间，`recorded_at` 为系统记录时间；业务时间乱序到达的版本标记 `is_backfill`（迟到补录）。

## 不变量

1. **不可覆盖**：版本只追加，按宗地构成哈希链；复核决定、证照状态变化同样以新版本表达，历史版本永不修改。
2. **当时有效版本可回放**：
   - `basis=recorded` —— 系统在该记录时刻已知的有效版本（补录前的回答保持不变）；
   - `basis=occurred` —— 按业务发生时间重放重建的状态（迟到补录落在其真实发生位置）。
3. **并发安全**：提交必须声明 `base_version`；与当前版本不一致时阻断并说明理由，阻断本身也入审计。
4. **复核不丢**：每次提交生成复核任务并持久化；服务恢复后未完成复核仍在原队列、顺序不变。
5. **脱敏按角色**：经办、复核、管理员见明文；村集体见成员姓名但证件号与电话脱敏；授权机构仅得核验结论，持证人姓名脱敏。
6. **审计完整**：提交、阻断、核验、复核决定全部入哈希链审计日志，任何角色越权访问被 403 阻断。
